# Mahkama prototype outcomes

- [ ] **Client dashboard and navigation:** The home view presents a clear Start a case action, active-case status, upcoming appointment, notifications, privacy/trust messaging, and navigation for Home, Cases, Find a lawyer, Messages and Profile; navigation changes the visible client screen without a full reload.
- [ ] **Ethiopia-focused case catalogue:** The client can browse many realistic Ethiopian legal case types including land/property, rent/eviction, family/divorce, child custody/maintenance, inheritance, criminal defense/police matters, employment/unpaid wages, business registration/partnership, contracts, debt recovery, consumer disputes, traffic/accidents, civil claims, immigration/residency, tax/customs, construction, intellectual property, domestic violence support and other legal help; category cards include English labels and visible Amharic cues.
- [ ] **Guided case intake:** The client can choose a case type, location, preferred language, urgency and plain-language description through a step-by-step intake; the UI preserves the selected context and ends with a case reference number plus a matching-results action.
- [ ] **Lawyer discovery and matching:** The matches view shows suggested verified Ethiopian lawyers with practice areas, location, languages, experience, availability, ETB consultation range, rating, review count, response time and a short “may fit” explanation; filtering/search/sorting update the visible list.
- [ ] **Lawyer profile and proposal comparison:** The client can open a lawyer detail view, inspect trust signals and proposal details, compare multiple proposals for the active case, and choose a lawyer without the UI claiming a guaranteed result or a single “best” choice.
- [ ] **Downstream service states:** The prototype includes visible next steps for selecting a lawyer, Chapa upfront payment, private text chat, separate secure case-document exchange, appointment request, completion confirmation and eligible review, with clear privacy boundaries and no client ID upload.
- [ ] **Responsive product polish:** The experience is usable at mobile and desktop widths, uses accessible contrast and focusable controls, has coherent loading/empty/success states, and avoids claims that the platform is a law firm or provides legal advice.
- [ ] **Managed delivery readiness:** `manus-routes.json` is served with the real route set, TypeScript diagnostics pass, the production build completes, and the Cloud dev server responds on the configured port and `/api/health`.
